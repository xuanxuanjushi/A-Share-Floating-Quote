# A股桌面盯盘小工具

一个轻量桌面悬浮盯盘工具，支持股票、ETF 和板块盯盘。标的和板块默认显示 3 个输入行，也可以在设置里继续添加更多。可以显示名称、当前价和涨跌幅。名称和价格都可以隐藏，窗口可右键拖动，并支持透明度和缩放设置。

内置市场指标支持黄金、布伦特原油、纳指、上证指数，可在设置里显示或关闭。

## 运行

```powershell
python app.py
```

也可以双击 `run.bat`。

## 使用

- 右键单击窗口：打开菜单。
- 右键按住拖动：移动窗口。
- 点击名称：隐藏或显示名称。
- 右键菜单 `设置`：分别设置标的代码/名称、板块代码/名称、名称隐藏、价格隐藏和刷新间隔。
- 右键菜单 `设置`：可以继续添加标的或板块，空行不会保存。
- 右键菜单 `设置`：可以开关黄金、布伦特原油、纳指、上证指数。
- 右键菜单 `透明度`：调节悬浮窗透明度。
- 右键菜单 `缩放`：等比例调节悬浮窗大小。
- 右键菜单 `回到屏幕内`：多屏切换、远程桌面或 Win11 缩放后窗口跑偏时，可把小窗拉回当前可见屏幕。
- 设置、缩放和透明度窗口会贴近悬浮窗弹出。
- 设置窗口会根据新增的标的或板块自动调整宽高，并限制在当前屏幕内。

窗口启动、移动和退出时都会自动检查位置，避免保存到屏幕外导致下次打开看不到。

## 数据来源说明

当前版本使用免费的公开行情源获取股票、ETF、黄金、布伦特原油、纳指、上证指数和板块数据，只适合个人小频率盯盘。布伦特原油使用东方财富 `B00Y` 当月连续口径。免费公开源可能出现限流、接口变化或短时不可用；如果以后失效，只需要替换 `stock_floater/market_data.py` 里的行情 provider。

个股和板块的涨跌幅都使用行情源返回的最新涨跌幅：盘中显示实时涨跌幅，盘后和盘前显示最近一个交易日的收盘涨幅。

板块行情会分页拉取东方财富行业和概念板块，支持 `BK0800` 这类不在第一页的板块代码。

如果某一次免费接口短暂失败，界面会保留上一轮有效行情，避免临时显示成 `--`。

刷新时只有显示内容发生变化才重绘界面，减少悬浮窗闪烁；股票、板块和市场指标会并行请求，避免互相拖慢。


刷新策略：交易活跃时段按设置的刷新间隔刷新，最低 1 秒；非活跃时段自动降到至少 30 秒，减少无意义请求。
